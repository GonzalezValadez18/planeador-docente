PLANEADOR DOCENTE - HTML, CSS Y JAVASCRIPT PURO

1. Abre index.html en Chrome, Edge o Firefox.
2. Llena los datos generales y el proyecto.
3. Agrega tantos días y criterios como necesites.
4. Usa Guardar para conservar la información en localStorage del navegador.
5. Usa Vista previa o Imprimir / PDF para generar un documento imprimible.

No requiere servidor, npm, frameworks ni conexión a internet.

Archivos:
- index.html
- styles.css
- app.js
